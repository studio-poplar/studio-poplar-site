# デシイリ SaaS：運用メモ

編集部（代表）がふだんやること、困ったときの見どころをまとめます。管理画面は `/deshiiri/admin`（許可した Google アカウントだけが入れます）。

## 自動で動いているもの（Vercel Cron、本番だけ）

| 時刻（日本時間） | 仕事 | 入口 |
|---|---|---|
| 毎日 22:00 | その日に届いた投稿の下書きを、まとめて Claude に頼む | `/deshiiri/api/cron/drafts-submit` |
| 30分ごと | 下書きの結果を取り込み、確認待ちが増えたら編集部にメール | `/deshiiri/api/cron/drafts-collect` |
| 毎時 5分 | 24時間返事のない本人確認を公開／見学の3日の再通知・7日の不成立 | `/deshiiri/api/cron/hourly` |
| 毎日 3:00 | バックアップ／1年たった若者の連絡先を消す | `/deshiiri/api/cron/nightly` |
| 毎日 9:00 | LINE の通数・写真の置き場・データベースの容量を数え、超えていたらメール | `/deshiiri/api/cron/morning` |

どれも `CRON_SECRET` がないと動きません（外から叩かれないように）。Vercel の Cron Jobs の画面で、最後に動いた時刻と結果を見られます。

## 毎日

- **確認待ち**（`/deshiiri/admin/review`）を見る。下書きの事実（道具・材料の名前、本人の言葉）を確かめ、「本人確認へ進める」。盛らない：本人が言っていない年数・金額・資格・お客様の名前は足さない。
- 「確認したいことがあります」が付いている投稿は、本人に LINE か電話で聞いてから進める。
- **見学の進行**（`/deshiiri/admin/visits`）で、「職人に届いた（返事待ち）」が長く止まっていないか見る。3日で1回だけ自動で知らせ直し、7日で「調整がつかなかった」になります。気になるときだけ、職人に電話する。

## 毎週

- **最近の投稿を並べて見る**（`/deshiiri/admin/recent`）で、書き出しや言い回しが似てきていないか見る。似てきたら、職人ごとの話し方メモや、確認待ちでの手直しで変える。
- 本人確認で「直したい」が来た投稿が、確認待ちに戻っていないか見る。

## 毎月

- **運用**（`/deshiiri/admin/ops`）で、LINE のプッシュの通数（無料は月200通、150通で警告）、写真の置き場（R2、8GB で警告）、データベース（Neon、0.8GB で警告）を見る。
- バックアップが毎晩増えているか見る（同じ画面に新しい順に出ます）。
- 月に1回、バックアップを1つ選んで `--dry-run` で中身を数えてみる（docs/deshiiri-restore.md）。

## 新しい職人を迎えるとき

1. **職人と招待コード**（`/deshiiri/admin/craftspeople`）で登録し、招待コード（6けた、14日有効）を出す。
2. 職人に LINE の友だち追加をしてもらい、コードを送ってもらう。
3. 話し方メモ（一人称・語尾・方言・口ぐせ）を、会ったときの印象で書いておく。下書きと Instagram 用文章に効きます。
4. 名刺やチラシには、職人の編集ページの「QR コード（PNG）を保存」で作った QR を使う。

## 困ったとき

| こんなとき | 見るところ |
|---|---|
| LINE に返事が来ない | LINE Developers の Webhook が「利用する」になっているか。Vercel のログで `/deshiiri/api/line/webhook` の失敗。Sentry。 |
| 下書きができない | Vercel の Cron Jobs で drafts-submit / drafts-collect が動いたか。Anthropic の Console の使用量とキー。確認待ちの「今すぐ下書きを作る」で1件だけ試せる。 |
| 職人ページに載らない | 投稿の状態が「公開中」か（届いた投稿）。職人ページは公開・取り下げのときに作り直されます。 |
| メールが届かない | Resend の画面の送信記録。迷惑メールのフォルダ。 |
| 写真が出ない | R2 の接続（管理画面の「接続を確かめる」）。 |
| プッシュが月200通を超えそう | 本人確認と見学の知らせはプッシュ（数える）。それ以外は返信（数えない）。超えると、その月はプッシュが送れません。有料プランに上げるかは代表が決める。 |
| データがおかしい・消えた | docs/deshiiri-restore.md の手順で、新しい Neon のブランチに戻して見比べる。 |

## 公開の前にやること（代表）

- 労働局への確認・規約と同意書・保険がそろうまで、本番の職人ページは一般に案内しない。
- そろったら Vercel の本番の環境変数に `DESHIIRI_SAAS_PUBLIC=1`（職人ページ・職種一覧を検索に出す）と `DESHIIRI_RULES_PUBLIC=1`（規約のページを出す）を入れ、`src/lib/deshiiri/rules-pages.ts` の本文を差し替えて `draft: false` にする。
