# src/fonts

Self-hosted subsets of two Google Fonts, built by `npm run fonts` (`scripts/build-fonts.mjs`).
`charset-full.txt` (Gothic) and `charset-repo.txt` (Mincho) list the characters each file contains.

| File | Font | License |
|---|---|---|
| `zen-kaku-gothic-new-*.woff2` | Zen Kaku Gothic New © Yoshimichi Ohira | SIL Open Font License 1.1 |
| `shippori-mincho-700.woff2` | Shippori Mincho © FONTDASU | SIL Open Font License 1.1 |
